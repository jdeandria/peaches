# Peaches UI kit

The Peaches design system: an M3 theme, in-house M3 Expressive components
and layout primitives. Everything is standalone, OnPush and signal-based. Import from `src/app/ui` (barrel
`index.ts`) or the individual files.

## Theme

- **Colours** — `theme/_palette.scss` is generated by
  `node scripts/generate-theme.mjs` (seed `#FFE5B4`: accents from M3 _fruit
  salad_, every surface role from _monochrome_; light on `:root`, dark under
  `prefers-color-scheme: dark`). Use Angular Material system tokens:
  `var(--mat-sys-primary)`, `--mat-sys-on-primary`, `--mat-sys-primary-container`,
  `--mat-sys-secondary-container`, `--mat-sys-tertiary`, `--mat-sys-error`,
  `--mat-sys-surface`, `--mat-sys-surface-container-{lowest,low,,high,highest}`,
  `--mat-sys-on-surface(-variant)`, `--mat-sys-outline(-variant)`, …
- **Type** — Roboto Flex (self-hosted). Classes for every M3 role:
  `.pch-display-{large,medium,small}`, `.pch-headline-*`, `.pch-title-*`,
  `.pch-body-*`, `.pch-label-*` (display-small, headline-medium/small,
  title-large and label-large use the heavier Expressive weights). In SCSS:
  `font: var(--mat-sys-title-medium)`.
- **Shape** — `--pch-radius-small` 8, `-medium` 12, `-large` 16,
  `-extra-large` 28 (hero cards, dialogs, sheets).
- **Motion** — `--pch-ease-emphasized`, `--pch-ease-emphasized-decelerate`
  (enter), `--pch-ease-emphasized-accelerate` (exit), `--pch-ease-standard`;
  `--pch-duration-short|medium|long` (200/300/500ms); springs as `linear()`
  easings with matching durations: `--pch-spring-{spatial,effects}-{fast,default,slow}`
  and `--pch-spring-…-duration` (generated `theme/_springs.scss`). All
  durations are 0 under `prefers-reduced-motion`. JS: `M3Springs`,
  `springCurve()`, `springDuration()`, and the `ReducedMotion` service
  (`inject(ReducedMotion).reduced()` signal).
- **Elevation** — `--pch-shadow-1|2|3`.
- **Icons** — Material Symbols Rounded (self-hosted):
  `<span class="material-symbols-rounded" aria-hidden="true">today</span>`;
  add `.pch-icon-filled` for the filled style. `<mat-icon>today</mat-icon>`
  also renders Material Symbols Rounded.
- **Helpers** — `.pch-visually-hidden`; `cssColor(value)` resolves a role
  name (`'primary'`, `'onPrimaryContainer'`), `'--custom-prop'` or CSS colour.
- **Material components** are themed to match: 48px pill buttons that morph to
  12px corners while pressed, extended FAB on primary-container with radius 16,
  `mat-card` radius 16, dialogs/bottom sheets 28, outlined fields 12,
  snackbars 8 (and above the nav bar), strong focus indicators.
- `--pch-bottom-inset` (set by the shell): height covered by the bottom nav
  bar on compact windows. Use it for anything `position: fixed` at the bottom.

## Shell

### `pch-shell` — `Shell` (`shell/shell.ts`)

App frame with `<router-outlet>` inside `<main>`. Navigation per M3 window
size class (pure CSS): bottom bar < 600px (68px), rail 600–839px (🍑, labels
under icons), extended rail ≥ 840px (200px, labels beside icons). Destinations
`NAV_DESTINATIONS`: Today `/` (also active on `/matchups/*`), Crates `/crates`
(also `/crates/*`), Exercises `/exercises`, Profile `/profile`. Active link
has `aria-current="page"` and a filled icon. Includes a "Skip to content"
button. Used as the parent route component in `app.routes.ts`.

## Page layout

### `pch-page` — `Page` (`layout/page.ts`)

| Input            | Type      | Default | Notes                                                         |
| ---------------- | --------- | ------- | ------------------------------------------------------------- |
| `title`          | `string`  | req.    | Large headline (`h1`, headline-medium).                       |
| `subtitle`       | `string`  | –       | Supporting text under the headline.                           |
| `toolbarTitle`   | `string`  | `title` | Fades into the sticky toolbar once the headline scrolls away. |
| `maxWidth`       | `number`  | `720`   | Content column cap (px); gutter 16px compact / 24px.          |
| `showBack`       | `boolean` | `false` | Back button: `Location.back()` if there is in-app history…    |
| `backLink`       | `string`  | `'/'`   | …else navigates here.                                         |
| `refreshable`    | `boolean` | `false` | Adds a Refresh icon button to the toolbar.                    |
| `refreshing`     | `boolean` | `false` | Disables the refresh button.                                  |
| Output `refresh` | `void`    |         | Refresh button clicked.                                       |

Slots: default (page content), `[pageActions]` (toolbar, use `mat-icon-button`s
with `aria-label`), `[pageFab]` (fixed bottom-end; use `mat-fab extended`),
`[pageBottomBar]` (sticky bar on surface-container, constrained to the column).

```html
<pch-page
  title="Crate"
  [subtitle]="crate.name"
  showBack
  backLink="/crates"
  refreshable
  (refresh)="reload()"
>
  <button pageActions mat-icon-button aria-label="Share">
    <span class="material-symbols-rounded" aria-hidden="true">share</span>
  </button>
  …content…
  <button pageFab mat-fab extended (click)="create()">
    <span class="material-symbols-rounded">add</span>New crate
  </button>
  <button pageBottomBar mat-flat-button class="full">Submit</button>
</pch-page>
```

### `pch-section` — `Section`

Inputs: `title: string` (required, rendered as `h2` title-medium), `top: number`
(space above, default 24). Slot: `[sectionTrailing]`.

```html
<pch-section title="Members"
  ><a sectionTrailing mat-button routerLink="invite">Invite</a></pch-section
>
```

### `pch-two-pane` — `TwoPane`

Slots `[primaryPane]` and `[secondaryPane]`: side by side 3:2 (24px gap) when
the component is ≥ 880px wide (container query), stacked below. Input
`stackedGap: number` (px between stacked panes, default 0).

```html
<pch-two-pane [stackedGap]="16"
  ><div primaryPane>…</div>
  <div secondaryPane>…</div></pch-two-pane
>
```

## Surfaces and lists

### `pch-card` / `[pch-card]` — `Card`

Inputs: `variant: 'elevated' | 'filled' | 'outlined'` (default `elevated`),
`interactive: boolean` (hover/focus lift and press state; automatic on `<a>` and
`<button>` hosts). CSS vars: `--pch-card-padding` (16px), `--pch-card-radius`
(16px; use `var(--pch-radius-extra-large)` for hero cards).

```html
<pch-card variant="filled">Static content</pch-card>
<a pch-card [routerLink]="['/crates', c.id]">…</a>
<button pch-card type="button" (click)="open()">…</button>
```

### `pch-list-card` — `ListCard`

Input `variant: CardVariant` (default `elevated`). Card with 4px vertical
padding whose children are separated by inset (16px) hairlines.

### `pch-list-row` / `a[pch-list-row]` / `button[pch-list-row]` — `ListRow`

M3 list item: 56px (72px with subtitle), 16px padding, 16px gap. Default
content = headline (body-large). Slots: `[rowLeading]` (avatar/icon),
`[rowSubtitle]` (body-medium, on-surface-variant), `[rowTrailing]`. Input
`interactive: boolean` (automatic on `a`/`button` hosts: state layer + focus ring).

```html
<pch-list-card>
  @for (m of members(); track m.id) {
  <a pch-list-row [routerLink]="['/peaches', m.id]">
    <pch-shaped-avatar rowLeading [shapeId]="m.id" [name]="m.name" />
    {{ m.name }}
    <span rowSubtitle>{{ m.record }}</span>
    <span rowTrailing class="material-symbols-rounded" aria-hidden="true">chevron_right</span>
  </a>
  }
</pch-list-card>
```

### `pch-empty-state` — `EmptyState`

Inputs: `icon: string` (Material Symbols name, required), `title: string`
(required), `message?: string`. Slot `[emptyAction]`.

```html
<pch-empty-state icon="inventory_2" title="No crates yet" message="Create one to get started.">
  <button emptyAction mat-flat-button (click)="create()">New crate</button>
</pch-empty-state>
```

### `pch-status-label` — `StatusLabel`

Dot + projected text in label-medium. Input `color?: string` (role or CSS
colour, default on-surface-variant).

```html
<pch-status-label color="primary">In progress</pch-status-label>
```

### `pch-date-badge` — `DateBadge`

Input `date: string` (LocalDate `yyyy-MM-dd`, required). 44px tile: weekday
(primary, uppercase) over day of month; announced as "Monday, March 3". Shows
"–" for invalid dates. Exported `parseLocalDate(iso)` → `{year, month, day,
weekday (1 = Mon … 7 = Sun)} | null` (no `Date`/time zones involved).

```html
<pch-date-badge [date]="round.startDate" />
```

### `pch-standings-table` — `StandingsTable`

Inputs: `rows: readonly StandingsRow[]` (required, in rank order),
`highlightPeachId?: string | null` (row on secondary-container, `aria-current`),
`label: string` (region name, default "Standings").

```ts
interface StandingsRow {
  peachId: string;
  name: string;
  wins: number;
  losses: number;
  ties: number;
  streak: string;
  onWinningStreak: boolean;
  form: readonly ('win' | 'loss' | 'tie')[];
  pointsFor: number;
  pointsAgainst: number;
}
```

Columns # · Peach · W-L-T · Streak · Form (last 5 dots, only when the table is
≥ 600px wide) · PF · PA. Scrolls horizontally when narrow; empty rows show an
outlined "No standings yet." card. `formatPoints(n)` = `Fmt.points`.

```html
<pch-standings-table [rows]="standingRows()" [highlightPeachId]="me()" />
```

## Expressive

### `pch-shaped-avatar` — `ShapedAvatar`

| Input        | Type                  | Default                                                    |
| ------------ | --------------------- | ---------------------------------------------------------- |
| `shape`      | `ShapeName \| 'auto'` | `'auto'` (from `shapeId`, else `name`)                     |
| `shapeId`    | `string`              | – (e.g. Peach or crate id)                                 |
| `name`       | `string`              | – when set, shows its initial instead of projected content |
| `size`       | `number`              | `40` (px)                                                  |
| `color`      | role / CSS colour     | `secondary-container`                                      |
| `foreground` | role / CSS colour     | `on-secondary-container`                                   |
| `label`      | `string`              | – (decorative/aria-hidden unless set)                      |

Shapes: `circle`, `cookie4`, `cookie6`, `cookie9`, `cookie12`, `clover4`,
`clover8`, `sunny`, `softBurst`. Person helper: `[shapeId]="id" [name]="name"`.
Content projection works for icons/images (clipped to the shape).
Functions: `shapeForId(id)` (stable hash of the id),
`initialOf(name)`, `shapePath(shape, size)`.

```html
<pch-shaped-avatar [shapeId]="peach.id" [name]="peach.displayName" [size]="48" />
<pch-shaped-avatar shape="sunny" color="primary-container" foreground="on-primary-container">
  <span class="material-symbols-rounded">inventory_2</span>
</pch-shaped-avatar>
```

### `pch-wavy-progress` — `WavyProgress`

Inputs: `value: number` (0..1, required; springs to new values), `flowing:
boolean` (travelling wave; reserve for one bar per screen), `color` (default
primary), `trackColor` (default secondary-container), `label?: string` (makes
it a `progressbar` with `aria-valuenow`; otherwise `aria-hidden` — show
progress as text too). 12px tall, full width.

```html
<pch-wavy-progress [value]="done / total" flowing label="Workout progress" />
```

### `pch-loading-indicator` — `LoadingIndicator`

Inputs: `size: number` (default 48), `contained: boolean` (on a circular
primary-container), `label: string` (default "Loading"). `role="progressbar"`.
Morphs and rotates; still under reduced motion.

```html
<pch-loading-indicator contained [size]="56" />
```

### `pch-button-group` — `ButtonGroup<T>`

Connected single-select group (radiogroup with arrow/Home/End keys).
Inputs: `options: readonly { value: T; label: string }[]` (required),
`selected: T | null` (model — use `[(selected)]`), `allowDeselect: boolean`,
`label?: string` (aria-label), `height: number` (default 48). Output
`selectionChange: T | null` (user changes only).

```html
<pch-button-group label="Range" [options]="ranges" [(selected)]="range" />
```

## Motion helpers

### `[pchStagger]` — `Stagger` directive

Staggered fade + slide-up entrance after `index × 40ms` (capped at 12) on the
default spatial spring; none under reduced motion.

```html
@for (c of crates(); track c.id; let i = $index) {
<a pch-card [pchStagger]="i" [routerLink]="['/crates', c.id]">…</a>
}
```

### `pch-animated-number` — `AnimatedNumber`

Inputs: `value: number` (required), `format: (v: number) => string` (default
rounds). Tweens on the slow effects spring; screen readers get the final value.

```html
<pch-animated-number class="pch-display-small" [value]="points()" [format]="formatPoints" />
```
